# 구글 드라이브 백업 설정

문서함 파일(웹·앱)과 사진 일기(앱)를 내 구글 드라이브 폴더에도 저장한다. 구글 드라이브는 공유 폴더 링크만으로는 앱이 파일을 쓸 수 없어서, 내 구글 계정에 작은 Apps Script(받는 쪽)를 한 번 배포해 그 주소로 보낸다.

## 1. Apps Script 배포(한 번, 약 5분, PC 권장)

1. <https://script.google.com> → **새 프로젝트**.
2. 기본 코드를 지우고 `tools/drive_backup.gs` 내용을 통째로 붙여 넣는다.
   - `TOKEN` : 앱에 넣을 비밀 키. 받은 '바로 붙여 넣을 파일'을 쓰면 이미 들어 있다.
   - `FOLDER` : 저장할 드라이브 폴더 링크(예: `https://drive.google.com/drive/folders/1AbC…`). 비워 두면 내 드라이브에 **윈난 여행 앱 백업** 폴더를 만든다.
3. 저장(디스크 아이콘) → 오른쪽 위 **배포 → 새 배포**.
4. 유형 선택(톱니) → **웹 앱**. 설명 아무거나, **실행 사용자: 나**, **액세스 권한: 모든 사용자**.
5. **배포** → **액세스 승인** → 내 구글 계정 선택 → "확인되지 않은 앱" 화면이면 **고급 → (프로젝트 이름)(으)로 이동** → **허용**. (내가 만든 스크립트가 내 드라이브에 쓰는 권한이다.)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.

## 2. 앱·웹에 넣기

- **더보기 → 설정 → 구글 드라이브 백업**: 웹 앱 주소와 백업 키(TOKEN)를 넣고 **저장·연결 확인** → "연결됨 · 폴더 「…」"가 나오면 끝.
- 기기마다 한 번씩 넣는다(주소·키는 그 기기에만 저장). 앱은 빌드 때 저장소 밖 `private.json`(`driveUrl`·`driveToken`)으로 기본값을 넣을 수 있다. 웹은 Cloudflare 변수 `PRIVATE_JSON` 에 같은 값을 넣으면 기본값이 된다.

## 3. 동작

- 문서를 넣거나 사진 일기를 추가하면 **바로 올린다**(인터넷이 없으면 건너뛴다).
- 문서함·사진 일기 위의 **드라이브로 백업 (N건)** 으로 아직 안 올린 것을 한꺼번에 올린다. 문서 화면의 **드라이브로 올리기** 로 한 건씩도 된다.
- 드라이브 폴더 구조: `문서함/D3/D3_제목_id.pdf`, `사진일기/D2/D2_1217-1530_12.jpg`(메모만 있는 일기는 `…_메모.txt`). 같은 이름이 있으면 다시 만들지 않는다.
- 설정 전이나 오프라인일 때는 문서 화면의 **공유** 로 휴대폰 공유 화면 → Google Drive 앱에 직접 저장할 수 있다.

## 보안

- 웹 앱 주소와 키를 아는 사람은 이 폴더에 파일을 **올릴 수만** 있다(읽기·지우기 불가). 키는 공개 저장소에 넣지 않는다.
- 키를 바꾸려면 스크립트의 `TOKEN` 을 고치고 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포한 뒤, 앱 설정의 키도 바꾼다.
