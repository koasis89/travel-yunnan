## 3. 알려진 제한

- 생체인증·위젯·알림 수신·외부 앱 연동은 자동 테스트 범위 밖이다(실기기 항목 10~18).
- 쿤밍 숙소 중국어 주소는 영문 주소를 옮긴 것이다. 숙소 페이지와 대조 후 틀리면 엑셀 수정 → `python3 tools/build_data.py`.
- 丽江粑粑·汽锅鸡 음식 사진 없음(엑셀에 CC 이미지 파일 없음).
