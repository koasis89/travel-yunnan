# 배포·설치 안내 (S7-4 ~ S7-6)

## 1. 서명 키

- 파일: `travel-yunnan-release.jks` (별명 `travelyunnan`, PKCS12, 유효 30년). 리포지토리에는 넣지 않는다.
- 보관: PC의 안전한 폴더와 클라우드 백업 1곳. 분실하면 같은 패키지명으로 덮어쓰기 설치가 불가능해 기존 설치를 지워야 한다.
- `android/keystore.properties` 에 아래 형식으로 둔다(git 제외).

```
storeFile=/경로/travel-yunnan-release.jks
storePassword=...
keyPassword=...
keyAlias=travelyunnan
```

## 2. 릴리스 빌드

```bash
python3 tools/build_data.py
cd android && ./gradlew assembleRelease
```

- 결과: `android/app/build/outputs/apk/release/app-release.apk`
- R8 매핑 파일 `android/app/build/outputs/mapping/release/mapping.txt` 를 버전별로 보관한다(충돌 로그 해독용).
- 디버그 빌드는 패키지명이 `kr.koasis.travelyunnan.debug` 로 분리되어 릴리스판과 나란히 설치된다. 0.6.0 이하 디버그판(패키지명이 같았음)은 릴리스 설치 전에 삭제한다.

## 3. 설치 (3인 기기)

1. APK 전송: 카카오톡 "나에게 보내기", 구글 드라이브, USB 복사 중 하나.
2. "출처를 알 수 없는 앱 설치" 허용 → 설치. Play 프로텍트 경고는 "무시하고 설치".
3. 첫 실행 시 알림 권한 허용. 더보기 → 교통·열차·알림에서 "정확한 알림 허용"도 켠다.
4. 더보기 → 긴급·여권에서 각자 여권 정보 입력(기기에만 암호화 저장).
5. 홈 화면 길게 눌러 "윈난 여행" 위젯 추가.
6. 고덕지도(高德地图)·DiDi·위챗·알리페이 설치 여부 확인.
7. 설정 → 배터리 최적화에서 이 앱을 제외(알림 지연 방지).

## 5. 업데이트 시 데이터 유지

- 같은 키로 서명한 상위 버전은 덮어쓰기 설치되며 체크·즐겨찾기·지출·일기·여권 정보가 유지된다.
- 원본 데이터(JSON)는 APK 에 포함되므로 앱 업데이트만으로 반영된다.
