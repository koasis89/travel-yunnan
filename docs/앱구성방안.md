## 1. 앱의 목적과 설계 원칙

이 앱은 범용 여행 앱이 아니라 **이번 여행 한 번을 위한 전용 동반 앱**이다. 엑셀에 정리된 일정·숙소·식당·회화를 현장에서 즉시 꺼내 쓰는 것이 목적이다. 설계 원칙은 다음 다섯 가지로 정한다.

1. **오프라인 우선**: 중국 현지에서 구글 계열 서비스가 차단되고 데이터가 불안정하므로, 모든 데이터·이미지·음성은 앱 안에 내장한다. 네트워크는 고덕지도(Amap)·DiDi·위챗 등 외부 앱으로 넘길 때만 사용한다.
2. **보여주기 모드**: 택시 기사, 호텔 직원, 식당 종업원에게 휴대폰 화면을 그대로 보여주는 상황이 많다. 글자를 크게, 화면을 밝게, 불필요한 UI를 숨기는 전용 화면을 둔다.
3. **세 번 터치 이내**: 급한 상황(기사에게 주소 보여주기, 결제 문장 찾기)은 홈에서 세 번 이내 터치로 도달해야 한다.
4. **오늘 중심**: 앱을 열면 현재 날짜·시각에 맞는 일정이 먼저 나온다. D1~D8 중 어느 날인지 사용자가 고르지 않아도 된다.
5. **3인 공유**: 세 사람이 같은 데이터를 각자 폰에 갖는다. 체크리스트·지출 기록만 로컬 상태이며, 필요 시 내보내기·가져오기로 동기화한다.

## 3. 화면 구성

하단 탭 5개를 기본 골격으로 하고, 홈에서 모든 긴급 기능에 바로 진입하는 구조로 한다.

```
[홈/오늘] [일정] [회화] [지도] [더보기]
                                 ├ 숙소
                                 ├ 맛집·음식
                                 ├ 교통·열차
                                 ├ 경비
                                 ├ 준비물
                                 ├ 유의사항
                                 └ 긴급·여권
```

### 3.1 홈(오늘) 화면

앱 실행 시 현재 날짜로 D1~D8을 자동 판별한다. 여행 전에는 "출발까지 N일"과 준비물 진행률을, 여행 후에는 지출 정산을 보여준다.

- **오늘 요약**: 일차, 경로(예: D5 백사→호도협), 해발·낮밤 기온·옷차림 한 줄
- **지금 일정 카드**: 현재 시각이 속한 상세일정 행을 크게 표시하고, 다음 행을 작게 표시한다
- **다음 이동 카드**: 열차(C118 08:27 등)·투어 픽업(05:45)·빵차(10:30)까지 남은 시간 카운트다운
- **바로가기 4개**: 오늘 숙소 택시 카드 / 오늘 식당 택시 카드 / 회화 즐겨찾기 / 오늘 지도
- **오늘의 주의**: 유의사항 시트에서 해당 일차와 연결된 항목(예: D3 케이블카 사전 구매, D5 큰 짐 Come Inn 전달)

### 3.2 일정 탭

- 상단에 D1~D8 가로 칩을 두고, 선택 일차의 상세일정을 타임라인으로 나열한다
- 각 행은 시간 · 출발지 → 경유 → 도착지 · 이동수단 아이콘 · 소요시간 · 팁으로 구성한다
- 행 안의 중국어 주소·숙소명·식당명은 자동으로 링크가 되어 택시 카드나 맛집 상세로 이동한다
- 행에 긴 중국어 메시지(D4 빵차 예약 요청, D6 샹그릴라 빵차 요청)가 붙어 있는 경우 "매니저에게 보여주기" 버튼을 노출한다
- 길게 누르면 "완료" 체크가 되어 지난 일정은 흐리게 처리한다

### 3.3 택시 카드(기사에게 보여주기)

사용자가 명시한 핵심 요구이다. 숙소·식당·역·관광지 전부에 공통으로 적용한다.

- **진입**: 홈 바로가기, 숙소·맛집 상세의 "택시" 버튼, 일정 행의 도착지 터치
- **화면 구성(세로)**
  1. 상단 한 줄: `请送我们到这个地址` (이 주소로 데려다 주세요) + 병음
  2. 중앙: 중국어 상호명(굵게, 36sp 이상) → 중국어 주소(28sp 이상, 자동 줄바꿈)
  3. 하단: 전화번호(터치 시 다이얼), 보조 문구(예: `我们有三个行李箱` 짐 3개)
  4. 맨 아래 작은 글씨: 한국어 이름과 예약번호(본인 확인용)
- **동작**
  - 진입 시 화면 밝기를 최대로 올리고 화면 꺼짐을 막는다. 나가면 원래대로 복귀한다
  - 가로 모드에서는 상호명·주소만 전체 화면으로 키운다
  - 화면 터치로 UI를 모두 숨기고 주소만 남긴다
  - "주소 복사" 버튼: 중국어 주소를 클립보드에 넣고, 설치된 경우 고덕지도·DiDi를 연다
  - 엑셀에 Amap 단축 링크(surl.amap.com)가 있는 항목은 "지도앱 열기" 버튼을 추가한다
- **특수 카드**
  - 물라뉴 탕수 호텔: 고성 내 차량 진입 불가 안내가 함께 뜬다. `请送我们到古城北门大水车附近，酒店会来接` 류의 보조 문장을 둔다
  - Come Inn: D5 기사에게 짐 전달 부탁 문장(`行李送到靠山十九度`)을 함께 표시한다
  - 역·공항: 쿤밍역(昆明站), 리장역, 샹그릴라역(香格里拉站), 창수이공항(长水国际机场)을 숙소와 같은 형식으로 둔다

### 3.4 회화 탭(중국어 문장)

TTS 텍스트 파일을 기반으로 하며, 각 항목은 **중국어 · 병음 · 한글 발음 · 한국어 뜻** 네 줄을 갖는다. 한글 발음은 엑셀 D6 행에 있는 방식("니하오, 워 시앙 위딩…")을 따라 전 문장에 추가한다.

- **상황별 묶음**(파일의 문장 순서를 그대로 따른다)
  1. 차량 예약·빵차: 你好 我要预订包车 / 在景区等一个半小时 / 然后送我们到茶马客栈 / 这辆车一共多少钱 / 行李送到靠山十九度 / 明天上午十点 / 去香格里拉 / 请告诉我车牌号 / 请给我师傅的电话
  2. 차 안에서: 师傅 请开空调 / 请关空调 / 师傅 不好意思 / 我要去洗手间 / 请停一下
  3. 숙소: 你好 我要入住 / 这是我的护照 / 有押金吗 / 可以微信支付吗 / 早餐几点到几点 / 无线网密码是多少 / 3인 엑스트라베드 확인(유의사항 시트)
  4. 식당: 服务员 点单 / 请给我菜单 / 有什么推荐菜 / 这个要一个 / 那个要一个 / 所有的菜都不要香菜 / 要一瓶冰啤酒 / 要一瓶矿泉水 / 服务员 结账 / 一共多少钱 / 我用微信支付 / 请扫我的码 / 可以用支付宝吗 / 请给我发票
  5. 매표·관광지: 你好 我要两张成人票 / 包含往返索道吗 / 可以刷护照进去吗
  6. 시장·쇼핑: 这个一斤多少钱 / 可以先尝尝吗 / 太贵了 / 便宜一点 / 我多买 送几个 / 请给我新包装
  7. 역·보안검색: 你好 我要核对车票 / 这是我的护照 / 行李放在这里 / 我没有违禁品 / 这是合规的充电宝 / 检票口在哪里
  8. 음식 주문: 我要一份过桥米线 / 汽锅鸡 / 野生菌火锅 / 牦牛肉火锅 / 丽江粑粑 / 酥油茶 / 不要辣 / 不要香菜
  9. 배달·기타: 유의사항 시트의 메이투안 주소 요청·프런트 보관 문구
  10. 긴 메시지(위챗 복사용): D4 호도협 빵차 예약 요청문, D6 샹그릴라 빵차 예약문 전문
- **단어장**: 52개 핵심 단어를 별도 탭으로 두고, 문장 안의 단어를 터치하면 단어 뜻이 풀이된다
- **재생**: 각 항목에 스피커 버튼을 둔다. 음성은 두 단계로 준비한다
  - 1순위: 빌드 시 미리 생성한 mp3를 앱에 내장(오프라인 보장, 발음 품질 고정)
  - 2순위: 기기의 Android TextToSpeech `zh-CN` 엔진(음원이 없는 경우 대체)
  - 느리게 재생(0.7배) 옵션과 3회 반복 옵션을 둔다. 원본 파일이 문장을 3회 반복 기록한 의도를 그대로 살린다
- **보여주기 모드**: 문장을 길게 누르면 택시 카드와 같은 전체 화면으로 중국어만 크게 띄운다
- **즐겨찾기·최근 사용**: 홈 바로가기에 연결된다
- **상황 자동 추천**: 홈에서 현재 일정 행의 이동수단이 "택시·DiDi"이면 차량 묶음, 도착지가 식당이면 식당 묶음을 상단에 띄운다

- 2차 개발에서 기기 GPS 좌표로 현재 위치 대략 표시를 검토한다(이미지에 좌표 보정 기준점 2개를 수동 지정)

### 3.6 숙소 화면

- 날짜순 6개 숙소 카드(쿤밍 2박은 "미정"으로 표시하고 확정 시 데이터만 교체)
- 카드: 한글·영문·중국어 숙소명, 중국어 주소, 전화, 객실, 예약번호, 예약자, 상태, 비고
- 버튼: 택시 카드 / 전화 / 주소 복사 / 체크인 문장(`你好 我要入住` + 엑스트라베드 확인문) / 와이파이·조식 문장
- 각 숙소에 "할 일" 체크: 물라뉴(위챗으로 하차 지점·짐 운반 요청), Rishine(호도협 차량 예약 요청), Come Inn(샹그릴라 빵차 예약), Oura Villa(D7 역 샌딩 요청)

### 3.7 맛집·음식 화면

- 일차·끼니별 선택지 ①②③를 카드로 나열하고, 중국어 상호·주소·추천 메뉴·예상비용을 표시한다
- 버튼: 택시 카드 / 주소 복사 / 주문 문장(추천 메뉴에 맞는 `我要一份…` 자동 생성) / 공통 주문 문장(향채 제외, 맵지 않게)
- **음식 도감**: 음식설명 시트 26종을 지역별로 묶고 사진·설명을 보여준다. 사진이 없는 음식은 중국어 명칭 카드로 대체한다
- **메뉴 포인팅 카드**: 음식 중국어명을 큰 글씨로 띄워 종업원에게 보여주는 화면. 수량(一个/一份/一瓶)과 요청(不要辣/不要香菜)을 토글로 붙여 한 문장으로 합성한다
- 영업시간·대기(예: 田村 대기 20분, 야크우유 에그타르트 품절 빠름) 메모를 배지로 표시한다

### 3.8 교통·열차 화면

- 열차 2건(C118 쿤밍→리장 08:27~12:54, C640 샹그릴라→쿤밍 10:05~16:03)과 대안(C644)을 카드로 둔다
- 출발 2시간·30분 전 알림, 역 도착 권장 시각, 개찰 마감(출발 20분 전) 표시
- 역에서 쓰는 문장(차표 확인, 여권 제시, 보안검색, 검표구 위치) 바로가기
- Klook 픽업 2건, 호도협 전용차·빵차 2건, 택시 예상 4건을 일정과 연결하여 표시
- 빵차 예약 실패 시 대안(티나객잔 → 샹그릴라 버스 시간표)을 유의사항에서 끌어와 표시

### 3.9 경비 화면

- 예산: 총비용 시트 4개 구분(교통·투어 / 숙박 / 식비 / 쇼핑·예비비)과 합계
- 지출 기록: 금액(¥ 또는 원), 구분, 메모, 결제수단(위챗·알리페이·현금·카드). 환율은 교통·투어비 시트 값(¥1 = 200원)을 기본으로 하되 수정 가능
- 일차별 예산 대비 지출 막대, 남은 현금 위안화 추적
- 정산: 3인 공동 지출과 개인 지출 구분, CSV 내보내기

### 3.10 준비물·날씨·유의사항

- 지역별 기온·옷차림 표를 일차와 연결하여 홈 상단에 "오늘 옷차림"으로 노출
- 준비물 체크리스트는 분류별 접기, 체크 상태 로컬 저장, 진행률 표시
- 유의사항 16항목은 일차 연결 항목과 공통 항목으로 나누고, 관련 문장이 있으면 회화로 바로 이동

### 3.11 긴급·여권 화면

- 생체인증 또는 PIN 뒤에 3인 여권 정보(영문명·번호·만료일) 표시. 저장은 Android Keystore 기반 암호화
- 숙소 전화 전체, 주중 한국대사관·쿤밍 총영사관 연락처, 현지 긴급번호(110·120·119)
- 고산병 대응 메모(산소 디퓨저 숙소, 산소캔 구입처), 보험 연락처 입력란
- "도움 요청" 보여주기 문장: `请帮我叫救护车` / `我有高原反应` 등은 2차에서 추가한다

## 4. 추가 아이디어

- **숫자 패드 카드**: 흥정·결제 시 금액을 큰 숫자로 띄워 보여준다. 중국어 숫자 읽기(一百五十)를 함께 표시한다
- **위챗 메시지 템플릿**: 숙소 매니저에게 보낼 긴 문장(빵차 예약, 짐 운반, 배달 주소)을 한 번에 복사하는 기능. 날짜·시간·인원 변수를 치환한다
- **알림 스케줄**: 투어 픽업(D3 05:45), 체크아웃 마감(D4 12:00), 열차 출발, 공항 출발(D8 19:30)을 설치 시 자동 등록한다
- **일출·일몰 카드**: 12월 윈난 기준 07:50 / 18:40을 D5 일조금산, D6 마니차 야경 일정에 붙인다
- **3인 역할 배지**: 예약자(JONGHOON KO / EUNCHORONG KO)를 숙소 카드에 표시하여 체크인 시 누구 이름으로 예약했는지 즉시 안다
- **홈 화면 위젯**: 다음 이동과 오늘 숙소 주소를 위젯으로 노출한다
- **사진 일기**: 일정 행에 사진·메모를 붙여 여행 후 기록으로 남긴다
- **데이터 갱신**: 엑셀을 수정하면 변환 스크립트로 JSON을 재생성하여 앱을 다시 빌드한다. 쿤밍 숙소 확정 시 이 경로를 사용한다

## 7. 확인·결정이 필요한 사항

1. 쿤밍 숙소 2박(12/16, 12/22)이 미정이다. 확정 후 숙소정보 시트에 추가하면 변환 스크립트로 반영한다.
2. 문장 음성은 사전 생성 mp3를 권장한다. 어떤 TTS 엔진으로 생성할지(Azure·Google·Edge TTS 등) 결정이 필요하다.
3. 한글 발음 표기는 현재 D6 문장 2건에만 있다. 49문장 전체에 추가하는 작업을 데이터 변환 단계에서 수행한다.
4. Amap 단축 링크 14건은 현지에서 고덕지도 앱이 설치된 경우에만 열린다. 링크 뒤에 중국어 상호 검색어를 항상 병기한다.
5. 여권 정보는 앱에 넣지 않고 종이·사진 사본만 쓰는 방안도 가능하다. 넣는 경우 생체인증 잠금을 필수로 한다.
6. 음식설명 시트의 이미지 26장은 Wikimedia Commons 라이선스(CC)이므로 앱 내 출처 표기 화면을 둔다.
7. 배포는 Google Play 없이 APK 직접 설치(3인)로 한다. 서명 키는 개인 보관한다.
